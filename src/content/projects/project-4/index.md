Cineview is a web application designed for movie enthusiasts to discover the latest films, add them to a personal watchlist, and share their thoughts through reviews.

I was responsible for both the design and development of the platform, translating a simple idea into a polished, user-friendly experience.

---

## Features 🎬

- Browse a constantly updated list of the latest and trending movies.
- Add movies to a personalized watchlist for easy tracking.
- Write and manage your own reviews for movies you’ve watched.
- Search for specific titles quickly with an intuitive search function.
- Responsive and clean UI designed to work seamlessly across all devices.

---

## Stack 🛠

For this project, I used a combination of:

- **React** for building the frontend components.
- **Bootstrap** to quickly style the app with a clean, responsive design system.
- **TMDB API** for accessing a rich database of movies, posters, and metadata.

I chose this stack to rapidly prototype and iterate on the app's features while ensuring a great user experience. Bootstrap helped in maintaining a consistent design language without starting from scratch.

---

## Results ✨

The app was well-received, particularly for its simplicity, modern look, and ease of use.

It also served as a great personal project to further solidify my skills in building API-driven React applications with a focus on user experience.
